# TradeBot Agent Factory v0.21 — запуск в Codex

Этот пакет содержит весь проект: исходный код MVP, `AGENTS.md`, готовую
проектную конфигурацию `.codex/`, 12 ролей агентов, спецификации, тесты,
handoff и контрольные manifests.

## Куда распаковывать

### Если у тебя уже есть Git-репозиторий с наработками

Не начинай проект с нуля и не продолжай работу прямо в старой ветке.

1. Переключись на последнюю рабочую ветку с твоими наработками.
2. Убедись, что её изменения сохранены отдельным commit.
3. Создай от неё ветку интеграции:

```bash
git switch -c feature/offline-mvp-v0.21
```

4. Распакуй содержимое папки `tradebot-agent-factory/` в корень репозитория.
   В корне должны оказаться `AGENTS.md`, `.codex/`, `tradebot_mvp/`,
   `specs/`, `tests/` и остальные каталоги проекта.
5. Не подтверждай массовую замену файлов вслепую. Если Git показывает
   конфликты с твоими файлами, попроси Codex сравнить и объединить их.

### Если Git-репозитория ещё нет

Распакуй `tradebot-agent-factory/` в постоянную папку и выполни:

```bash
git init
git switch -c feature/offline-mvp-v0.21
```

## Первый запуск

Открой в Codex именно корень `tradebot-agent-factory`, подтверди доверие
проекту и начни новый сеанс. Затем отправь:

```text
Работаем с существующим проектом TradeBot Agent Factory v0.21. Это
продолжение разработки, а не новый проект.

Сначала ничего не изменяй.

1. Подтверди корень рабочего проекта.
2. Перечисли загруженные файлы AGENTS.md.
3. Проверь .codex/config.toml и 12 файлов в .codex/agents/.
4. Прочитай AGENTS.md, HANDOFF_NEW_CHAT_RU.md и docs/MVP_ROADMAP_RU.md.
5. Запусти python scripts/self_check.py.
6. Запусти python -m unittest discover -s tests -v.
7. Подтверди: v0.21 — только OFFLINE_SIMULATION; Telegram API, Bitget,
   paper/live trading и реальные деньги не подключены.
8. Если manifests совпадают, не повторяй закрытые проверки и не возвращайся
   к PM-DEC-007.
9. Предложи короткий план Slice 02: импорт локальной истории Telegram,
   edits/replies/deletes и event-time replay. До моего подтверждения код
   не изменяй.
```

Если команда `python` не найдена, используй `py` в Windows или `python3`
в Linux/macOS.

Не запускай `prompts/start-factory.md`: он предназначен для полного цикла
TB-001 и вернёт проект к слишком широкому процессу.
